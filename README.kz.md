# Dombra Studio: виртуалды домбыра

Қазақ домбырасының 40 нақты жазбасы. Әр нота 3 round-robin нұсқасымен ойнайды. Екі ішекпен ойналатын қағыс пресеті және шанақты соғу дыбысы бар. Файлдар 24-bit / 44.1 kHz WAV форматында.

## Пресеттер
| Файл | Плагин (тегін) | Не ойнайды |
|---|---|---|
| `Dombra.dspreset` | [DecentSampler](https://www.decentsamples.com/product/decent-sampler-plugin/) (VST3/AU/AAX) | Жеке ноталар, A2–E5 |
| `Dombra-Qagys.dspreset` | DecentSampler | Қағыс: екі ішек бірге, F3–C5 |
| `Dombra.sfz`, `Dombra-Qagys.sfz` | sforzando, sfizz, TX16Wx, Logic Sampler | Дәл осылар, SFZ форматында |

Папканы толық күйінде көшіріңіз: `Samples/` пресеттің жанында тұруы керек.

## Клавиатура
- **C3–C5**: нақты ноталар, A = 440 Гц бойынша бапталған (баптау файлдардың өзінде).
  - C3–E3: тек үстіңгі ішек.
  - F3–G4: екі ішек кезектеседі, сондықтан қайталанған нота бірдей естілмейді.
  - G#4–C5: тек астыңғы ішек.
- **A2–B2, C#5–E5**: шеткі үлгілерден созылған қосымша ноталар.
- **C2**: шанақты соғу.
- **Velocity** тек қаттылықты басқарады, тембр өзгермейді.
- **Қағыс**: перне астыңғы ішектің нотасын береді, үстіңгі ішек одан кварта төмен бірге естіледі. Төмен және жоғары қағыс кезектесіп ойнайды.
- **Ре–Соль бұрауы**: DAW-та +2 жарты тонға транспозициялаңыз.

DecentSampler тұтқалары: Volume, Attack, Release, Tone (төменжиілікті сүзгі), Reverb, Room.

**Round-robin.** Әр нота ±5 цент және деңгейі аздап өзгеше 3 нұсқамен кезектесіп ойнайды. Екі ішек кезектесетін пернелерде 6 нұсқа болады. Сондықтан қатар қайталанған нота бірдей естілмейді. SFZ-те дәл осы әсер `pitch_random` / `amp_random` арқылы жасалған.

## Ноталар ойнататын құралға арналған файлдар
`u0.mp3 … u19.mp3`, `d0.mp3 … d19.mp3`, `beat.mp3`: бастапқы файлдармен атаулары бірдей, сондықтан ескілерін тікелей ауыстыра аласыз. Деңгейлері теңестірілген, A=440-қа бапталған, гуілі жойылған, ноталардың соңы қалпына келтірілген (mp3, 192 kbps).

| Папка | Бұрау | u0 | d0 | d19 |
|---|---|---|---|---|
| `Notes-D-G/` | Ре–Соль (дәстүрлі) | D3 | G3 | D5 |
| `Notes-C-F/` | Жазбаның өз биіктігі | C3 | F3 | C5 |

Қосымшаңыз u0-ді "Ре" деп көрсетсе, `Notes-D-G` жинағын алыңыз. `Notes-C-F` жинағы түпнұсқа тембрге сәл жақынырақ, себебі транспозицияланбаған.

Ескерту: mp3 кодері әр файлдың басына шамамен 25 мс "бос" дыбыс қосады. ffmpeg оны LAME тегі арқылы алып тастайды (тексерілді: 5 мс қалады). Браузерлер тексерілген жоқ, кей ойнатқыштар бұл кідірісті алып тастамауы мүмкін. Кідіріс сезілсе, `Samples/u0.wav … d19.wav` файлдарын пайдаланыңыз. Олар C-F биіктігінде.

## Бастапқы жазбаларға не істелді
| Мәселе | Шешім |
|---|---|
| Ноталар A=440-тан 22–75 цент төмен | Әр нота өлшеніп, файлдың өзінде бапталды (қате ≤ 2.2 цент) |
| Гуіл және DC (80 Гц-тен төмен энергияның 82 %-ы 20 Гц-тен төмен), шу едені ≈ −43 дБ | 30 Гц HPF (нөлдік фаза), шанақтың соққысы сақталады → шу едені ≈ −57 дБ |
| AAC декоды 0 dBFS-тен +1.9 дБ асады | Әр файл −1 dBFS-ке нормаланды, клиппинг жоқ |
| Файлдар −42…−65 дБ-де кенет бітеді | Гармоникалар бойынша ресинтез, −70 дБ-ге дейін табиғи өшеді |
| Басында 32–176 мс үнсіздік | Кесілді |
| Ноталардың деңгейі 19 дБ-ге дейін ажырайды | Әр нота −1 dBFS шыңға дейін көтерілді, тым қатты ноталар ғана −12 дБ RMS-ке түсірілді. Лимитер жоқ, шертпе сығылмайды |
| Бір нотаны қайталағанда бірдей естіледі | 3 round-robin (±5 цент, ±0.6 дБ) |

Толық талдау графиктерімен (спектрограммалар, дейін/кейін тыңдау): https://azamaperdeev05.github.io/dombra-studio/

## Шектеулер
- Бастапқы файлдар 64 kbps AAC. Жиілік жолағы мен кодек артефактілерін қалпына келтіру мүмкін емес.
- Әр нотаға бір ғана динамика бар. Бір жазбадан жасалған жасанды p/mf қабаттары шертпенің 2 кГц-тен жоғары энергиясын 6.8 дБ-ге әлсіретіп, дыбысты "басып" тастады, сондықтан олар алынды. Нақты ақырын/қатты шертпелер тек жаңа жазбадан алынады.
- Синтезделген соңы таза өшеді. Сондықтан нота ұзақ ұсталғанда фондағы әлсіз шу (−60 дБ шамасында) жоғалғаны естілуі мүмкін.
- Бастапқы репозиторийде (metahdev/Dombra) лицензия жоқ. Сатуға немесе таратуға дейін авторынан рұқсат алыңыз.

## Қайта құрастыру

```
python3 build.py <u0..u19.m4a, d0..d19.m4a, beat.mp3 жатқан папка>
python3 test_build.py <сол папка>
```
